NOTE / 001

从一个 HTML 文件开始

2026 年 10 月 8 日　文陶　／　网页制作

一个网页可以从一个很普通的文本文件开始。给它取名 index.html，用浏览器打开，里面的文字就能显示出来。小站也是这样搭起来的。

先搭好结构

下面是一个最小的例子。head 里放标题和字符编码，body 里放读者能看到的内容。中文页面记得声明 UTF-8，文件本身也要用 UTF-8 保存。

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <title>我的小站</title>
</head>
<body>
  <h1>欢迎光临</h1>
  <p>这是我的第一段文字。</p>
</body>
</html>

标题用 h1、h2 等标签，正文用 p。先把内容按顺序写清楚，再去调整字体和颜色，会容易一些。

图片与链接

插入图片用 img，其中 src 指向图片文件，alt 描述图片内容。首页的照片放在 images 文件夹里，引用的是相对路径。

<img src="images/zhalong-cranes.jpg"
     alt="鹤群飞过扎龙湿地">
<a href="posts/first-page.html">阅读全文</a>

这里容易出错的是路径。从首页去文章页写 posts/first-page.html；从文章页回首页，要先用 ../ 返回上一层。文件名的大小写也要一致，换到服务器上以后尤其要注意。

把样式单独放好

本站的几个页面共用 css/style.css。修改这个文件，就能一起调整页面的背景、边框和字号，不用逐页找同一段样式。

<link rel="stylesheet" href="css/style.css">

/* style.css 中的一条规则 */
a { color: #174d85; }

页面用了一个居中的外框，左边是导航，右边是正文。屏幕变窄时，正文和导航改成上下排列。表格只用来放“网站 / 用途”这样的数据。

最后检查一次

  • 每个链接都点开一次，看看目标对不对。
  • 把整个文件夹复制到别处打开，确认没有误用本机的绝对路径。
  • 缩窄浏览器窗口，看看文字、图片和表格有没有挤出去。
  • 发布以后再看一遍，确认线上版本已经更新。

页面做好以后，源码还是几份可以直接读的文件。以后想加一篇文章，复制一页、改掉标题和正文，再给首页加上链接就行。

参考：MDN：HTML 基础语法；MDN：link 元素。
